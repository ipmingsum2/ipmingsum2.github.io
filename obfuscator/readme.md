# Alvin's Obfuscator

Based on Prometheus by Elias Oelschner, https://github.com/prometheus-lua/Prometheus

Private Roblox Luau obfuscator with Discord-approved access. Obfuscation runs locally in the browser. Version 1.1.0 adds configurable output limits in KB/MB and optional enhanced VM routing. LOLvm is disabled below 1 MB; builds that cannot fit preserve the previous output. Every output starts with an Alvin's Obfuscator version comment. Super adds two permuted VM layers, braided string encoding, generated junk and bounded integrity checks. License notices are in THIRD-PARTY-NOTICES.txt.
