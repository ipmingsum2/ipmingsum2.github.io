# Alvin's Obfuscator

Based on Prometheus by Elias Oelschner, https://github.com/prometheus-lua/Prometheus

Private Roblox Luau obfuscator with Discord-approved access. Obfuscation runs locally in the browser. Version 1.5.7 adds a modern Apple-style interface, larger SF Pro Display headings, and editable strings.json loaded on refresh. It supports typed Luau declarations, unions, type aliases, generics and casts; compile-time types are erased during parsing. Source and output filenames are editable, including after a build. General text uses SF Pro from the requested Apple font stylesheet; code remains monospace and interface icons use SVG. Output limits in KB/MB and enhanced VM routing remain available. LOLvm is disabled below 1 MB; builds that cannot fit preserve the previous output. Every output starts with an Alvin's Obfuscator version comment. Super adds two permuted VM layers, braided string encoding, generated junk and bounded integrity checks. License notices are in THIRD-PARTY-NOTICES.txt.
