Connect your experience

Use the public Ranking module from a Roblox server script.

1. Set up your group

Sign in with Discord, verify Roblox, and register your group. For Open Cloud, use a Creator Dashboard key with group member read and write access for that group. The site owner can configure a cookie slot in Cloudflare.

Register a group ↗

2. Use your group key

Issue a group key from the dashboard and save it in your Roblox experience secret store under RANKING_API_KEY. Enable HTTP Requests in your Roblox experience. Ask the Ranking publisher for the published module’s numeric asset ID.

local HttpService = game:GetService("HttpService")
local Ranking = require(MODULE_ASSET_ID)
local ranker = Ranking.new({
    ApiKey = HttpService:GetSecret("RANKING_API_KEY"),
    MaxRank = 200,
    AllowTerminate = false,
})

local result, message = ranker:SetRank(targetUserId, 30)
if not result then warn(message) end

SetRank, Promote, Demote and Terminate accept a Player or user ID. An optional final request ID lets callers safely retry the same request. A successful call returns the previous and resulting rank. Promotion and demotion move to the next actual role. The configured rank cap applies to both the current and target roles.

3. Configure termination

Set a termination role in group settings and enable AllowTerminate in your game. A cookie-connected group can explicitly opt in to removal with rank 0.
