DEVELOPER DOCUMENTATION

Connect your experience

Install Ranking in Roblox Studio and call its API from a server script.

1. Set up your group

Sign in with Discord or a passkey, verify Roblox, and register your group. For Open Cloud, use a Creator Dashboard key with group member read and write access for that group. The site owner can configure a cookie slot in Cloudflare.

Register a group

2. Install Ranking in Studio

Download the Studio setup
  1. In Explorer, right-click ServerScriptService, choose Insert from File, and open the downloaded file.
  2. Open Loader under Ranking System and Config. Enter the published module asset ID in mainModuleId.
  3. Issue a group key from the Ranking dashboard and paste it between the quotes after ApiKey = in Config.
  4. Open Security in Game Settings and turn on Allow HTTP Requests.

3. Call RankingAPI from a server script

local Ranking = require(game:GetService("ServerStorage"):WaitForChild("RankingAPI"))
local function setMemberRank(targetUserId, newRank)
    local result, message = Ranking:SetRank(targetUserId, newRank)
    if not result then warn(message) end
end

SetRank, Promote, Demote and Terminate accept a Player or user ID. Pass the same optional request ID to retry a request. A successful call returns the previous and new rank. The rank cap applies to both the current and target roles.

4. Configure termination

Set a termination role in group settings and enable AllowTerminate in Config. A cookie-connected group can opt in to removal with rank 0.
